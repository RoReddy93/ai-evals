## Fallback methods (non-Level 3 items)

### L2 · Context Specificity (UX Trust · P1)
- **Method:** weekly audit to ensure we don't provide poor response quality to the user
- **Why this fallback is defensible:** The risk is P3 because it doesn't cause reputation damage. We avoid things like slangs, missing crucial info etc.

### L2 · Source Attribution Failure (Robustness · P1)
- **Method:** weekly audit to ensure we don't fabricate or fail to provide sources in case users want to reference
- **Why this fallback is defensible:** The risk is P2 because not everyone checks sources and it doesn't mean a response is wrong if source attribution failed

### L2 · Data Bias (Fairness · P2)
- **Method:** Weekly audit to check if real data is statistically similar to reference distribution
- **Why this fallback is defensible:** The risk is P2 because it's rare that data bias will occur in one week assuming there is no bias in the training data. We usually see this happen if we don't check for bias over a period of time.
